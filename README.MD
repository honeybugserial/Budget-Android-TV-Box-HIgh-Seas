### **Button-Mapper-Remap-Your-Keys_v3.35.apk**  
Utility for remapping hardware buttons on Android devices. Supports assigning custom actions to remote buttons, volume keys, and other physical controls.  
Website: [https://buttonmapper.app/](https://buttonmapper.app/)

### **Emby_2.1.26g_212600_arm64-v8a_armeabi-v7a_mod.apk**  
Client application for Emby media servers. Used for streaming movies, TV shows, and personal media libraries to Android TV devices.  
Website: [https://emby.media/emby-for-android.html](https://emby.media/emby-for-android.html)

### **Projectivy-Launcher_v4.68.apk**  
Alternative Android TV launcher designed for projectors and TV boxes. Provides customizable layouts, input source shortcuts, and better navigation compared to stock OEM launchers.  
Forum thread: [https://xdaforums.com/t/app-android-tv-projectivy-launcher.4436549/](https://xdaforums.com/t/app-android-tv-projectivy-launcher.4436549/)

### **smarttube_stable.apk**  
YouTube client optimized for Android TV. Removes ads, improves navigation, and adds features not available in the standard YouTube for TV app.  
Website: [https://smarttubeapp.github.io/](https://smarttubeapp.github.io/)

### **TELEVIZIO_com.ottplay.ottplay_v1_9_3_21_mod.apk**  
Live TV / IPTV player. Supports playlist loading, EPG display, channel groups, and general IPTV streaming on Android TV.  
Website: [https://televizo.net/](https://televizo.net/)
